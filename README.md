## A project to explore

### [Smartzer · User management application](https://github.com/robinucar/smartzer)

I built Smartzer as a full stack technical assessment. The React client and Express API share TypeScript definitions in an Nx workspace. The API stores user records in PostgreSQL using Prisma.
